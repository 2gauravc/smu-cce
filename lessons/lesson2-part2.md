## **1. filings.ipynb**

This notebook retrieves financial data for a stock using the `yfinance` library.

**What it does:**
- Defines a function `get_financials(ticker)` that takes a stock ticker symbol (like "MU" for Micron)
- Fetches and displays three financial statements:
  - **Income Statement** - Shows revenue, expenses, and profits
  - **Balance Sheet** - Shows assets, liabilities, and equity
  - **Cash Flow** - Shows money coming in and going out
- Runs the example for "MU" (Micron Technology)

---

## **2. news.ipynb**

This notebook fetches the latest news articles for a stock.

**What it does:**
- Defines a function `get_news(ticker)` that takes a stock ticker
- Retrieves news articles about that stock using yfinance
- Displays the top 5 news articles with:
  - Article title
  - Description (first 200 characters)
- Runs the example for "GOOG" (Google)

---

## **3. stock_price_ratings.ipynb**

This notebook gets current stock price and analyst recommendations.

**What it does:**
- `get_price(ticker)` - Fetches and displays the current stock price
- `get_analyst_ratings(ticker)` - Fetches analyst ratings history and shows the latest 10 recommendations
- Runs examples for "MU" (Micron Technology)

All three notebooks use the **yfinance library** to pull financial data from Yahoo Finance.
